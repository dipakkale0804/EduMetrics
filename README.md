# EduMetrics - Academic Risk Compass

EduMetrics is a web-based application designed to help educators and administrators identify students at academic risk. By analyzing student data, the platform provides insights into performance, attendance, and other key metrics, enabling early intervention and support.

## Features

- **Student Data Upload**: Upload CSV files containing student data for analysis.
- **Risk Assessment**: Predict academic risk levels (High, Medium, Low) based on performance, attendance, and other factors.
- **Performance Visualization**: Interactive charts and graphs to visualize test and assignment scores.
- **Student Profiles**: Detailed profiles for each student, including attendance, risk scores, and predicted grades.
- **Dashboard Overview**: Summary of student risk levels and performance metrics.
- **Dark Mode Support**: Toggle between light and dark themes for better accessibility.

## Technologies Used

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Data Visualization**: Recharts
- **State Management**: React Context API
- **Routing**: React Router
- **Utilities**: Radix UI components, React Hook Form
